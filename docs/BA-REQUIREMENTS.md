# BA Requirements – Bootstrap Restyling

## Overview

This document outlines the requirements for the login page restyling and team page for the Week 4 Mock Sprint.

The goal is to improve the appearance of the login page and create a team page that shows information about each team member.

## Login Page

The login page is **styling-only**.

The existing login functionality should not be changed.

The design can update:

* Layout
* Colours
* Fonts
* Input field styling
* Login button styling
* Spacing and alignment

No new login features are required for this sprint.

## Team Page

The team page should include:

* Team name
* Member photo
* Member name
* Member role
* Short introduction/blurb

Each team member should have their information displayed clearly.

## Display Rules

* The team name should be easy to see.
* Member names and roles should not be empty.
* Member photos should use a consistent size.
* A placeholder image can be used if a member does not have a photo.
* Long names or blurbs should not break the page layout.
* The page should remain readable on smaller screens.

## Edge Cases

The design should consider:

* Missing profile photo
* Missing member information
* Long member names
* Long blurbs
* Incorrect login details
* Different screen sizes

## Acceptance Criteria

The requirements are met when:

* The login page has been visually restyled.
* Existing login functionality remains unchanged.
* Login leads to the team page.
* The team name is displayed.
* Each member has a photo or placeholder.
* Each member's name and role are displayed.
* Each member has a short blurb.
* The design handles the listed edge cases.

## Handoff

The UX designer can use these requirements to create the login and team page designs.

The BA will review the UX design against these requirements before it is approved for development.
